# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт учебного интернет-магазина цифровой техники: главная страница, каталог, карточка товара, оформление заявки и контакты.

## Ссылка на опубликованный проект

GitHub Pages: https://marni52.github.io/kr1-html-css-shop/

## Как посмотреть проект

Открыть ссылку GitHub Pages или скачать репозиторий и открыть файл `index.html` в браузере.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `product.html` — карточка товара;
- `order.html` — оформление заявки;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `js/main.js` — файл JavaScript (модальное окно и обработка формы на главной);
- `js/order.js` — обработка формы на странице заявки;
- `images/` — папка для изображений;
- `sitemap.xml` — карта сайта;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов (`--space-xs` - `--space-xl`);
- переменные для цветов и скруглений;
- состояния `:hover`, `:active`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`, разделённый на смысловые блоки.

## Дополнительные элементы

- `sitemap.xml` — простая карта сайта;
- Open Graph-теги — базовая разметка для отображения ссылок (`images/preview.jpg`);
- хлебные крошки на внутренних страницах;
- плавная прокрутка к якорям и подсветка цели якоря через `:target`.

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для шапки (логотип + меню) и основного меню;
- Flexbox для внутренней структуры карточек товаров (кнопка прижата к низу карточки);
- CSS Grid для сетки карточек (`.products-grid`, `repeat(3, 1fr)`);
- CSS Grid для страницы каталога с фильтрами и списком товаров (`grid-template-areas: "filters products"`);
- CSS Grid для формы фильтров.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта (`site-header__inner`, `site-header__logo`);
- `site-nav` — основная навигация (`site-nav__list`, `site-nav__item`, `site-nav__link`, модификатор `site-nav__link--active`);
- `breadcrumbs` — хлебные крошки (`breadcrumbs__link`, `breadcrumbs__current`);
- `hero` — первый экран главной страницы;
- `section` — раздел страницы (`section__title`, `section__text`);
- `products-grid` — сетка товаров;
- `product-card` — карточка товара (`__title`, `__description`, `__price`, `__old-price`, `__badge`, `__actions`, `__button`, модификаторы `--featured`, `--discount`);
- `product` — страница товара (`__gallery`, `__image`, `__badge`, `__info`, `__price`);
- `product-table` — таблица характеристик (`__caption`, `__cell`);
- `catalog-layout`, `catalog-filters`, `catalog-products`, `filters-form` — страница каталога;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки (`__field`, `__label`, `__input`, `__select`, `__textarea`, `__hint`, `__actions`);
- `button` — кнопка (модификаторы `--primary`, `--secondary`, `--disabled`);
- `site-footer` — подвал сайта;
- `back-to-top` — кнопка «Наверх».

id используются только для якорных ссылок и JavaScript, в CSS стилизация идёт только через классы, inline-стилей нет.

## Позиционирование

- `position: sticky` — шапка сайта остаётся вверху при прокрутке;
- `position: relative` у карточки товара и `position: absolute` у бейджей «Скидка» и «Новинка»;
- `position: fixed` — кнопка «Наверх» в правом нижнем углу;
- `z-index` — шапка и кнопка «Наверх» отображаются поверх содержимого.
