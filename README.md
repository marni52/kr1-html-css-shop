# ShopProject — интернет-магазин цифровой техники

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

Дисциплина: «Фронтенд и бэкенд разработка».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина цифровой техники и аксессуаров: главная страница, каталог, страница товара, оформление заявки и контакты. Проект выполнен без CSS-фреймворков, JavaScript используется только для модального окна и проверки форм.

## Ссылка на опубликованный проект

## Как открыть проект

1. Открыть ссылку GitHub Pages в браузере.
2. Или скачать репозиторий (`git clone https://github.com/marni52/kr1-html-css-shop.git`) и открыть файл `index.html` в браузере.

Сборщики и установка зависимостей не нужны.

## Используемые технологии

- HTML5 (семантическая разметка, формы, таблица, `<dialog>`, `<details>`);
- CSS3 (переменные, Flexbox, Grid, позиционирование, псевдоклассы состояний);
- JavaScript (минимально: открытие модального окна и проверка форм);
- Git, GitHub, GitHub Pages.

## Что реализовано по требованиям КР №1

- **Семантика:** `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`; на каждой странице один `main`, уникальные `title` и `meta description`.
- **Навигация:** единое меню на всех страницах, активный пункт выделяется модификатором `site-nav__link--active` и атрибутом `aria-current="page"`; хлебные крошки на внутренних страницах; якорные ссылки `index.html#advantages`, `#popular`, `#reviews`, `#contacts`, `contacts.html#faq`.
- **Карточки:** блок `product-card` с изображением, категорией, названием, описанием, ценой и кнопками; сетка через CSS Grid.
- **Таблица:** характеристики товара на `product.html` (`caption`, `thead`, `tbody`, `th`, `td`), полосы «зебра» и подсветка строки при наведении.
- **Формы:** модальная форма заявки (`index.html`, `product.html`) и полная форма на `order.html`; у всех полей есть `label`, `id`, `name`, используются `required`, `type="email"`, `type="tel"` с `pattern`, `minlength`, `min`/`max`.
- **Модальное окно:** `<dialog>` с методом `showModal()`, закрывается кнопкой, клавишей Esc и кликом по фону.
- **CSS:** внешний файл, переменные в `:root`, состояния `:hover`, `:active`, `:focus-visible`, `:disabled`, `:target`.
- **Flexbox и Grid:** Flexbox — шапка, меню, кнопки, содержимое карточки; Grid — сетки карточек, преимуществ, отзывов, макет каталога «фильтры + товары» (`grid-template-areas`), страница товара, страница заказа, подвал.
- **Позиционирование:**
  - `position: sticky` — шапка сайта, фильтры каталога, блок «Как проходит заказ»;
  - `position: relative` + `position: absolute` — бейджи «Хит», «Скидка», «Новинка» в карточках и бейдж скидки на картинке товара;
  - `position: fixed` — кнопка «Наверх»;
  - `z-index` — шапка (10) и кнопка «Наверх» (20) поверх содержимого.

## Самостоятельные доработки

Сверх пошаговых методических указаний в проекте сделано:

1. **Собственное оформление и наполнение.** Магазин цифровой техники с реальными товарами, характеристиками и ценами вместо «Товар 1, 2, 3»; собственные SVG-иллюстрации товаров.
2. **Дополнительные разделы главной страницы:** преимущества магазина сеткой из 4 карточек, блок акции (`aside`), отзывы покупателей.
3. **Улучшенные карточки:** изображение, категория, бейджи через `position: absolute`, старая перечёркнутая цена, модификаторы `--featured`, `--discount`, `--out-of-stock` (у товара не в наличии кнопка отключена).
4. **Подробная страница товара:** рейтинг, наличие, список особенностей, таблица характеристик, блок «С этим товаром покупают», быстрая заявка в модальном окне.
5. **Сценарий заявки:**
   - кнопка «Оформить заявку» передаёт выбранный товар в адресе (`order.html?product=headphones`), и он сразу выбирается в форме;
   - кнопка «Быстрая заявка» на странице контактов открывает модальное окно на главной (`index.html#order`);
   - окно закрывается кликом по затемнённому фону;
   - после отправки показывается сообщение, и страница прокручивается к нему.
6. **Исправление ошибки из методических указаний.** Правило `[aria-invalid="true"]` проигрывало по специфичности правилу для полей, и ошибочные поля не подсвечивались. Селектор уточнён (`.order-form__input[aria-invalid="true"]`).
7. **Каталог:** sticky-фильтры, дополнительные группы фильтров («Наличие»), сортировка, кнопка «Сбросить».
8. **Доступность:**
   - видимый фокус у всех интерактивных элементов;
   - `aria-current` у активного пункта меню;
   - подсказки к полям через `aria-describedby`;
   - `role="status"` у сообщений об успехе;
   - `alt` у всех изображений;
   - звёздочки обязательных полей;
   - `scroll-padding-top`, чтобы sticky-шапка не перекрывала раздел при переходе по якорю.
9. **Частые вопросы** на `<details>`/`<summary>` (раскрываются без JavaScript), расширенный подвал из трёх колонок, кнопка «Наверх».
10. **Комментарии в коде:** каждая строка CSS и JavaScript и каждый элемент HTML снабжены пояснением.
